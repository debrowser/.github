<h1 align="center">Debrowser</h1>

<p align="center">
  A fast, native browser for iPhone and iPad, with real DevTools built in.
  <br>
  <a href="https://debrowser.app"><strong>debrowser.app</strong></a>
</p>

Debrowser is an everyday browser first. The DevTools stay out of the way until you open them:

- **A complete browser**: tabs, a Start Page with Favorites, Bookmarks, Reading List and History, and system-standard gestures and motion.
- **Elements and Styles**: inspect the live DOM and computed CSS of any page.
- **Console, Network and Storage**: logs, requests, cookies and storage, captured on the device itself.
- **Open in Debrowser**: send any link from the Share sheet.
- **No Mac, no cable, no proxy**: everything runs on the iPhone or iPad.

Debrowser is built on WebKit with public Apple APIs only. Inspected values always show where they came from; anything a browser on iOS can't measure is marked unavailable instead of guessed.

Debrowser is in development and not yet on the App Store.
